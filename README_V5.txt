WAOULA CMS V5 PRO

MISE À JOUR DEPUIS V4
1. Dans Supabase > SQL Editor, exécuter supabase-update-v5.sql une seule fois.
2. Sur GitHub, remplacer index.html et admin.html.
3. Conserver config.js et les médias existants.
4. Le ZIP contient les médias à la racine ET dans assets/ pour fonctionner avec les deux structures GitHub.
5. Attendre 1 à 3 minutes puis actualiser.
