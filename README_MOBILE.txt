CORRECTION MOBILE WAOULA

Cette version affiche entièrement l’image ou la vidéo d’accueil sur téléphone.
Le média utilise object-fit: contain sur les écrans de 768 px ou moins.
Des bandes noires peuvent apparaître : c’est normal et cela évite le recadrage.

Publication GitHub :
1. Décompresser le ZIP.
2. Envoyer tout le contenu du dossier waoula-boutique-main sur GitHub.
3. Conserver le dossier assets comme dossier.
4. Commit changes, attendre GitHub Actions vert, puis actualiser le site.
