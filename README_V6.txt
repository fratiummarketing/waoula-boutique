WAOULA CMS V6 — VERSION COHÉRENTE

1. Sur GitHub, remplace tout le contenu du dépôt par le contenu de ce dossier.
2. Conserve config.js avec ton URL et ta clé publique Supabase.
3. Dans Supabase, exécute supabase-update-v6.sql une seule fois.
4. Attends le déploiement GitHub Pages vert.
5. Administration : /admin.html
6. Boutique : /?v=6

La V6 affiche désormais une erreur visible si la boutique ne peut pas lire site_settings.
Les images existent dans le dossier assets/ pour éviter les erreurs 404.
